# Help — Aetherium

Welcome to Aetherium. This built-in help provides quick guidance for common tasks and pointers to deeper documentation.

## Getting Started

- New Chat: Start a conversation from the App Menu or the sidebar.
- New Note: Create notes from the App Menu or the Notes view.
- Preferences: Open `Preferences` to configure themes, models, and integrations.

## Shortcuts

- `Ctrl/Cmd + Shift + P` — Open Command Palette
- `Ctrl/Cmd + = / - / 0` — Increase / Decrease / Reset font size

## Troubleshooting

- If Ollama-backed features are missing, ensure Ollama is running on `http://localhost:11434`.
- If a view looks broken, try `Help → Report Issue` (or open DevTools with `F12`).

## More Documentation

For detailed architecture and advanced guides, see the project's `docs/` folder in the repository.
